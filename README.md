# ArgaLink

The official Dynamo package by [ArgaLink](https://www.argalink.com/), focused on improving the visualisation of abstract geometric objects such as coordinate systems, planes, and vectors.

ArgaLink nodes provide larger, clearer representations in Dynamo's 3D background preview, making orientation, axes, and normal directions easier to identify and understand.

## Included nodes

- **VisualiseCoordinateSystem** - Displays a coordinate system with clear, colour-coded X, Y, and Z axes.
- **VisualiseVector** - Displays a vector with enhanced visibility, making its direction easier to identify.
- **VisualizePlane** - Displays a plane with enhanced visibility, including its normal direction.

## Usage

Add one of the visualisation nodes to your Dynamo graph and connect the geometric object you want to inspect.

> **Tip:** Connect a Number Slider to the `Scale` input to adjust the visualisation scale interactively.

## Compatibility

- Dynamo 4.0-4.x
- Revit 2027
